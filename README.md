# 🎵 Spotify Dashboard – Excel Data Analysis Project

## 📌 About the Project

This project is an **interactive Spotify Dashboard created using Microsoft Excel**.
I worked with a Spotify songs dataset and analyzed different aspects of the data such as **artists, genres, song popularity, yearly releases, energy, danceability, valence, and other audio features**.

The main purpose of this project was to practice **data cleaning, data analysis, Pivot Tables, Excel formulas, and dashboard creation** and convert raw Spotify data into meaningful and easy-to-understand insights.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze Spotify song data using Excel.
* Understand the distribution of songs across different years.
* Identify popular artists and genres.
* Analyze song popularity.
* Study audio characteristics such as energy, danceability, loudness and valence.
* Create meaningful metrics from the dataset.
* Present the analysis through an interactive and visually organized dashboard.

---

## 📊 Dataset

The dataset contains information about Spotify songs and their audio characteristics.

Some of the important columns include:

* **Title** – Name of the song
* **Artist** – Artist who performed the song
* **Top Genre** – Genre associated with the song
* **Year** – Release year
* **Beats Per Minute (BPM)** – Tempo of the song
* **Energy** – Energy level of the song
* **Danceability** – How suitable the song is for dancing
* **Loudness (dB)** – Loudness of the track
* **Liveness** – Presence of live performance characteristics
* **Valence** – Musical positivity/happiness of the song
* **Acousticness** – Acoustic characteristics of the song
* **Popularity** – Popularity score of the song
* **Length** – Duration of the song

The workbook contains around **1,994 song records** and information from hundreds of artists.

## 📁 Workbook Structure

The Excel workbook is organized into different sheets for data preparation and analysis:

| Sheet                            | Purpose                                                      |
| -------------------------------- | ------------------------------------------------------------ |
| **Spotify Data**                 | Original Spotify dataset                                     |
| **Data**                         | Prepared/cleaned dataset used for analysis                   |
| **No of release each year**      | Analysis of number of songs released in different years      |
| **Popular Songs**                | Analysis related to song popularity                          |
| **Top 5 Popular Genres**         | Identifies the most popular genres based on popularity score |
| **Top 10 Artists & their Genre** | Analysis of artists and their popularity                     |
| **Energy Graph**                 | Comparison of different audio characteristics                |
| **Valence**                      | Analysis of average valence across years                     |
| **Metrics**                      | Key calculated metrics from the dataset                      |
| **Dashboard**                    | Final Spotify dashboard                                      |
